# Synthetic pharmaceutical quality fixtures

Everything in this directory is **FICTIONAL TEST DATA — NOT A COMPANY RECORD**.
It exists only to exercise PharmaAgent OS access, relationship, evidence-anchor,
and impact-analysis controls without using confidential or regulated records.

`corpus.v1.json` is a small Milestone 0 seed, not the complete demonstration
corpus. Every document carries its own identity, revision, effective date,
fictional owner, lifecycle status, section anchors, relationships, and ACL.

The data must never be:

- represented as an approved SOP, policy, training record, or quality record;
- imported into a production QMS, EDMS, LIMS, MES, or learning system;
- used to determine compliance, disposition product, or initiate CAPA; or
- relabeled with the name of a real company, site, employee, or product.

The fictional organization name, people, systems, and records are deliberately
invented. Tests enforce the synthetic classification and closed relationship
graph.
