# Visual simplification — 2026-09-09

The user requested fewer long explanations and a more visually understandable
interface. This release changes presentation on Home, Research, Help, quick chat
and the sidebar service overview. Research execution, API contracts, database
configuration and ownership controls are unchanged.

## Result

- A shared three-step diagram distinguishes employee goal setting, agent research
  and employee brief review. The research composer uses a compact version so its
  input and primary action remain accessible on narrow screens.
- Home uses short task rows with meaningful icons. Quick-chat examples still
  prefill their complete editable prompts without sending them automatically.
- Research stages and actions have relevant icons and concise labels. Four recent
  recorded actions appear first; the full history remains available on request.
  Plans default closed and display the real step count.
- Scope and saving information expands on demand. Saved FDA source scope and
  the need for human review remain visible. Full generated findings, citations,
  questions, source excerpts and exports are preserved. Limitations and the
  detailed review note remain accessible in an expandable brief section.
- Help uses a task directory, icon-based control reference and short expandable
  answers. Korean and English retain the existing enlarged type scale.

- Local API/worker integration with a deliberately scripted model completes a
  research task with real persistence and polling: four recent actions expand to
